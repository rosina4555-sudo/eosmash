# Eosmash Web

Competitive gaming platform waitlist landing page.

## Stack

- Vue 3 + Vite + TypeScript
- Tailwind CSS 4
- Vue Router
- Lucide Vue icons (`@lucide/vue`)

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Brand tokens

Design tokens live in `src/styles/tokens.css`. Primary palette: Midnight Navy + Electric Lime.

See `project.md` for the full product and design brief.
